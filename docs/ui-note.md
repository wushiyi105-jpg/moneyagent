# UI 说明：钱袋

- **谁在什么时刻打开**：给每周想知道钱花哪的家庭。
- **首屏任务句**：本周的钱，花到哪了。
- **主操作**：按「说一笔支出 → 确认金额类别 → 对账到月度」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：便携账夹；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：便携账夹。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给每周想知道钱花哪的家庭：一句话变成待确认账条，退款跟原消费一起看，月度差异能点回每一笔。
